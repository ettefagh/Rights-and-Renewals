# Brand logos and Media

Search native Media → Brand logos first. Reuse the correct asset; check brand
identity and provenance, not just filename. Record original source, retrieval
date, transformations and usage considerations in the editorial task; use caption
for suitable attribution. Use ready raster media for the public logo route;
never bypass native SVG restrictions.

Native editable metadata includes alt, caption, folderId, focalX and focalY.
Set useful alt such as “Example Fitness logo.” Preserve real dimensions and
system upload metadata; do not fabricate storage rows/readiness. Upload a new
asset for changed bytes, then choose it in Brand Policy logo. A Media upload does
not create the brand link. Keep unrelated draft content out of publication.

After authorized publication check `/wiki/<brand-slug>` and
`/api/brand-policy-logos/<brand-slug>` against the intended published reference,
without preview. Verify actual rendering/accessibility when possible; metadata
alone is not visual proof. Check references before deleting/replacing media.
Use `fields.py --collection brand_policies --fields logo` for the custom field.
