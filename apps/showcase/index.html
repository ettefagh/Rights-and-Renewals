🤖 AI Agent Quick-Connect (MCP 2024-11-05)

Fügen Sie diese Konfiguration in Ihre claude_desktop_config.json ein: 

{
  "mcpServers": {
    "cmlab-warranty": {
      "command": "npx",
      "args": ["-y", "@cmlab/warranty-mcp-server"]
    }
  }
}

Fügen Sie diesen Server in Settings > Features > MCP in Cursor hinzu: 

{
  "mcpServers": {
    "cmlab-warranty": {
      "url": "https://[project].page.dev/api/mcp/sse"
    }
  }
}

Cloudflare Pages Function JSON-RPC 2.0 Edge Endpoint: 

POST https://[project].page.dev/api/mcp
Content-Type: application/json

{
  "jsonrpc": "2.0",
  "id": "demo-1",
  "method": "tools/call",
  "params": {
    "name": "policy_lookup",
    "arguments": { "service_slug": "spotify" }
  }
}

Direkter Start über die lokale Node.js Stdio Schnittstelle: 

npx @cmlab/warranty-mcp-server
